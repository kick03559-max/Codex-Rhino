## 关键技术决策

- Rhino 7 使用 IronPython 2.7。后续通过 MCP 执行代码时，导入语句和辅助函数必须放在同一个 `main()` 函数内；禁止 f-string、类型注解、walrus 运算符等现代 Python 语法。
- 几何按功能分图层，茶几与画框完全分离；后续修改优先通过图层和对象名操作，不进行全场景删除或合并。
- 茶几采用独立命名：`CoffeeTable_Top`、`CoffeeTable_Leg_Front`、`CoffeeTable_Leg_BackLeft`、`CoffeeTable_Leg_BackRight`。
- 材质纹理文件使用绝对路径写入 Rhino 材质和对象 UserText；移动项目文件夹后若 Rhino 找不到贴图，需要在 Rhino 材质编辑器中重新指定贴图路径。
- 使用 Rhino 7 标准材质的 `Shine` 近似粗糙度，没有建立 Rhino 8/PBR 专用的真实 roughness 通道。

## 已知问题

- 参考图没有提供真实尺寸，1200 mm 桌面直径、520 mm 总高及其他尺寸均为按图估算的白模参数，后续应以实测尺寸替换。
- 当前模型是可编辑白模，未建立真实木板拼接、榫接、内部结构、五金或生产级倒角细节。
- 桌面与圆周边缘仍由同一个 Brep 和近似盒式映射承担，边缘木纹不是独立的端木纹理；如需生产级或高质量渲染，应拆分桌面上表面、侧边和底面后分别映射。
- 桌腿使用立面平面映射以保证正面竖向木纹，圆柱侧面可能出现接缝或纹理重复；如需无缝环绕，应建立专用圆柱 UV 或单独制作纵向无缝贴图。
- FHL 输出是依据产品图生成的材质参考图，未进行颜色标定、无缝边界检测或物理尺度标定。
- Rhino 7 的标准材质只用 `Shine=18/255` 近似粗糙度；最终渲染若要求真实 PBR，需要在 Rhino 渲染器中进一步配置粗糙度、凹凸和法线。
- 关闭 Rhino 后，下一次继续前需要重新启动 Rhino 7 和本地 `rhino7_mcp` 连接；项目模型不会自动保持 MCP 会话。

## 失败方案与处理结果

- 首次 Rhino 建模脚本因 MCP 包装层的命名空间隔离报 `name 'rg' is not defined`；已将导入和辅助函数全部移入 `main()` 后成功执行。
- FHL 材质图第一次请求在服务端终止，插件自动重试后成功生成；最终输出为 Images API 路由的 PNG。
- 桌腿首次使用圆柱映射时，视口显示纹理方向不理想；改用旋转纹理加立面平面映射后，桌腿恢复竖向木纹。
- 桌面首次使用圆柱映射产生不自然的同心折线；已改为盒式映射，最终视口效果可接受。
- 初次创建项目目录时，PowerShell 误将多个路径传给一个 `-LiteralPath` 参数导致失败；已改为逐个创建目录并完成资产复制。
