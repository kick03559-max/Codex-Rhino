# 参考图 → Rhino 建模 → FHL 木纹材质流程

## 1. 参考图分析阶段

先把图片作为形态和材质参考，不把图片中无法确认的尺寸当成事实。分析至少包括：

- 主体类别和构件数量；
- 正视、俯视或透视关系；
- 结构层级；
- 可能的尺寸比例；
- 材质颜色、纹理方向、粗糙度和反射；
- 哪些细节可见，哪些细节不能从图中确认。

提示词模板：

```text
根据这张产品图准备 Rhino 建模方案，只做方案分析，不修改当前模型。
请列出：主体构件、可见结构、估算比例、需要确认的尺寸、建议图层、对象命名、建模顺序、材质方案和验收标准。
不要虚构参考图中不可见的结构。
```

## 3. 通过 FHL Image Gen 生成材质图

前提：已安装 `fhl-image-gen` 插件，并且 FHL 配置有可用 worker。先检查配置，不要输出完整密钥：

```powershell
node "C:\Users\admin\.codex\plugins\cache\fhl-plugins\fhl-image-gen\0.2.1\scripts\generate.mjs" --get-config
```

单张产品图转材质图时使用 Images API 单图编辑，不要切换到 Responses 路线，也不要把一个请求拆成多个 worker。示例：

```powershell
$scriptPath = "C:\Users\admin\.codex\plugins\cache\fhl-plugins\fhl-image-gen\0.2.1\scripts\generate.mjs"
$source = "D:\项目目录\参考图\圆形实木茶几_白底产品图.png"
$prompt = "根据这张白底圆形实木茶几产品图，提取并生成一张可用于三维建模材质的无缝平铺木纹贴图。只呈现木材表面，不要桌子轮廓、桌腿、透视、背景、阴影、文字或水印。延续参考图的暖棕色旧木与粗糙实木质感：细密横向木纤维、自然浅深棕色变化、少量真实木结和细微磨损，哑光表面，中等粗糙度约 0.5。整体为均匀平面正视材质样本，纹理自然连续，适合 Rhino 茶几桌面与圆柱桌腿使用。"
node $scriptPath --edit --image $source --prompt $prompt --aspect 1:1
```

成功后保留插件输出的原始 PNG。不要覆盖原始输出；如果需要桌腿竖向木纹，可另存旋转 90° 的副本。

## 4. 材质图方向处理

- 桌面：使用原始横向木纹图。
- 桌腿：将纹理图旋转 90°，让木纹方向沿 Z 轴。
- 原图和旋转副本都放在项目的 `资产` 目录，文件名要能说明用途。

PowerShell 生成旋转副本示例：

```powershell
Add-Type -AssemblyName System.Drawing
$bitmap = New-Object System.Drawing.Bitmap($source)
$bitmap.RotateFlip([System.Drawing.RotateFlipType]::Rotate90FlipNone)
$bitmap.Save("D:\项目目录\资产\木纹材质_桌腿竖向.png", [System.Drawing.Imaging.ImageFormat]::Png)
$bitmap.Dispose()
```

## 5. 在 Rhino 中应用材质

Rhino 7 标准材质可以先实现可用的产品预览：

1. 为桌面和桌腿分别建立对象材质。
2. 指定木纹 PNG 为漫反射纹理。
3. 桌面使用盒式或平面映射，保持桌面木纹横向。
4. 桌腿使用旋转纹理和立面映射，保持木纹沿 Z 方向。
5. 设置低光泽，例如 `Shine=18/255`，作为中等粗糙度近似。
6. 重新捕获 Rhino 视口，检查纹理是否拉伸、倒置、重复或出现不自然接缝。

推荐的 Codex 提示词：

```text
将项目资产中的木纹材质应用到 CoffeeTable_* 对象，不修改几何结构。
桌面使用原始木纹图，木纹沿 X 方向；桌腿使用桌腿竖向副本，纹理沿 Z 方向。
桌面使用盒式映射，桌腿使用立面映射；材质设为暖棕色、哑光、中等粗糙度。
完成后读取对象 UserText 和材质路径，并捕获视口检查。若纹理方向不正确，先说明修正方案再修改。
```

## 6. 材质验收

至少检查：

- 桌面颜色是否接近参考图；
- 桌面木纹是否大体沿横向；
- 桌腿木纹是否沿竖向；
- 边缘是否出现过强的条纹、同心折线或贴图拉伸；
- 光泽是否过高；
- 视口材质是否会因贴图路径移动而丢失；
- Rhino 文件保存后是否仍能读取贴图。

## 7. 当前案例的已知限制

当前茶几桌面和边缘仍是一个 Brep，边缘贴图属于近似效果；桌腿使用立面映射保证正面竖向方向，侧面可能出现接缝。生产级效果应拆分桌面上表面、端面和底面，再分别做 UV 或材质。
